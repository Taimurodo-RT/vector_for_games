# Motif

Локальный редактор векторной анимации для игр, в духе Rive. Сцену можно написать коротким скриптом, увидеть сразу на холсте и
доделать мышью: правки с холста записываются обратно в текст скрипта.

Сейчас в репозитории первая версия редактора и командная строка `motif`. Рантайм для Godot 4.7 (.NET) идёт следующим этапом.

![Окно редактора: скрипт, холст, слои и таймлайн](docs/editor.png)

## Сборка и запуск

Нужен Rust 1.95 или новее.

```sh
cargo run --release -p motif-editor -- examples/bounce.msc
```

Холст рисует [Vello](https://github.com/linebender/vello) на GPU через wgpu (на Windows это DirectX 12 или Vulkan). Если GPU
недоступен, редактор сам переходит на CPU-рендер (tiny-skia), это видно в строке состояния внизу.

На Linux нужны `libxkbcommon-x11` и драйвер Vulkan или OpenGL (подойдёт программный `mesa-vulkan-drivers`).

## Что умеет редактор

* **Скрипт слева, холст в центре.** Каждое изменение текста сразу перерисовывает сцену. Пока в скрипте ошибка, на холсте
  остаётся последняя рабочая версия, а под текстом видна строка и причина.
* **Визуальная доводка.** Объекты выбираются кликом на холсте или в списке слоёв и двигаются мышью или стрелками (Shift — шаг 10).
  Справа редактируются позиция, размер, угол, масштаб, прозрачность, заливка и обводка. Каждая правка меняет число прямо в
  скрипте, поэтому текст и картинка всегда совпадают.
* **Формулы не ломаются.** Если значение задано через `let`, выражение или цикл, редактор не трогает формулу, а дописывает
  правку в блок `override { }` в конце файла.
* **Анимации.** Внизу выбирается анимация, есть пуск/пауза (пробел) и ползунок времени.
* **Запись ключей.** Когда выбрана анимация, любая правка (мышью, стрелками или в «Свойствах») ставит ключ на текущем
  времени прямо в блок `anim` скрипта. Если ключ на этом времени уже есть, меняется только его значение, кривая остаётся.
  У нового трека первым ключом становится значение из сцены на 0 с, поэтому правка анимируется, а не заменяет значение
  целиком. Ключи выбранного объекта видны ромбиками на таймлайне, «‹ ключ» и «ключ ›» переходят между ними,
  «Удалить ключи здесь» убирает ключи объекта на текущем времени. Анимированные свойства отмечены красным.
* **Пиксельное превью.** Сцена рендерится без сглаживания в заданную ширину (8–1024 px) и приводится к палитре сцены
  или к загруженной `.pal`. Так видно, что получится после пикселизации, ещё до экспорта.
* **Экспорт** кадров PNG и палитры `.pal` (меню «Пиксели и экспорт»).
* Открытие и сохранение `.msc`, отмена и повтор (Ctrl+Z, Ctrl+Shift+Z / Ctrl+Y), «Вписать» (F). Если файл поменяли в другой
  программе, редактор перечитает его сам, когда в нём нет несохранённых правок.
* Колесо — масштаб, средняя кнопка, Alt+перетаскивание или перетаскивание по пустому месту — сдвиг холста.

## Скрипт сцены (`.msc`)

Одна строка — один объект: `тип id ["Имя"] свойства…`. Вложенность задаётся фигурными скобками.

```text
artboard "Главный" 480x360 bg #fff4e4

let ink = #1b1d24

ellipse ball "Мяч"  at 150 150  size 72  fill #ff5a36  stroke ink 4
star    star        at 340 150  size 130 points 5  fill #ffc531

group coins at 36 40 {
  for i in 0..5 {
    ellipse coin{i} at {i * 28} 0 size 16 fill #ffd23f
  }
}

anim Idle 1.2s loop {
  ball.y   0: 120 ease-in | 0.6: 278 ease-out | 1.2: 120
  star.rot 0: 0 linear | 1.2: 72
}
```

| Что | Запись |
| --- | --- |
| Типы | `rect`, `ellipse`, `star`, `polygon`, `group` |
| Позиция центра | `at x y` |
| Размер | `size w [h]` |
| Скругление, лучи, внутренний радиус звезды | `r 8`, `points 5`, `inner 0.5` |
| Поворот (градусы), масштаб, прозрачность | `rot 15`, `scale 1.2 [0.8]`, `opacity 0.5` |
| Заливка и обводка | `fill #ff5a36` / `fill none`, `stroke #000 2` |
| Скрыть | `hidden` |
| Переменные и выражения | `let gap = 28`, `{i * gap + 4}` в значениях и id |
| Циклы | `for i in 0..5 { … }` |
| Анимация | `anim Имя 1.2s [loop] { объект.свойство время: значение [кривая] \| … }` |
| Кривые | `linear`, `ease-in`, `ease-out`, `ease-in-out` (по умолчанию), `hold`, `spring` |
| Ручные правки поверх формул | `override { coin2.y = 12 }` |
| Комментарии | `// …` или `#` в начале строки |

В анимации и `override` свойства пишутся так: `x y w h rot sx sy opacity r points inner fill stroke stroke_w`.

Полный пример — [`examples/bounce.msc`](examples/bounce.msc).

## Командная строка `motif`

Те же сцены можно проверять и рендерить без окна, например в скриптах сборки игры:

```sh
cargo run --release -p motif-cli -- check  examples/bounce.msc
cargo run --release -p motif-cli -- render examples/bounce.msc -o ball.png --scale 2
cargo run --release -p motif-cli -- frames examples/bounce.msc --anim Idle --fps 12 --width 120 --no-aa -o out/idle
cargo run --release -p motif-cli -- palette examples/bounce.msc -o out/scene.pal
```

## Пикселизация: PixaTool

У PixaTool нет командной строки, поэтому Motif готовит для неё файлы.

* **PixaTool.** `frames` складывает кадры `ИМЯ_0000.png…`, которые PixaTool обрабатывает пакетом. `palette` сохраняет цвета
  сцены в JASC `.pal` (не больше 192 цветов, это предел PixaTool), чтобы пикселизация не придумывала лишних оттенков.
* **Пакетная обработка.** PixaTool берёт список кадров и пишет в выбранную папку `ИМЯ_0000_processed.png…`.
* **Pixel FX Designer** (частицы от того же автора) читает те же JASC `.pal`, так что палитра у сцены и эффектов может быть общей.
* **Превью в редакторе.** Кнопка «Пиксельное превью» показывает сцену в целевом разрешении и палитре, поэтому размеры и толщину
  линий удобно подбирать до экспорта. `--no-aa` и шаговое время (`--fps 12`) дают кадры, с которыми PixaTool проще работать.

## Устройство

| Крейт | Что делает |
| --- | --- |
| `motif-core` | Модель сцены: объекты, трансформации, цвета, анимации и кривые |
| `motif-script` | Лексер, парсер и вычислитель `.msc`; запись визуальных правок обратно в текст |
| `motif-render` | Список отрисовки, CPU-рендер (tiny-skia), сцена Vello (`gpu`) |
| `motif-pixel` | Палитры JASC, квантование, рендер кадров анимации |
| `motif-cli` | Команда `motif` |
| `motif-editor` | Окно редактора (eframe/egui + Vello) |
