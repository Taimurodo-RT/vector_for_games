# Embedded portable CSS fonts

Liberation Sans Regular and Bold, unmodified from the official Liberation Fonts
2.1.5 binary release. The family provides metric compatibility with Arial.
Liberation Serif Regular/Bold and Liberation Mono Regular/Bold come unmodified
from the same archive, with Times New Roman and Courier New-compatible metrics.
