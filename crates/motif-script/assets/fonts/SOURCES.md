# Embedded CSS sans fonts

Liberation Sans Regular and Bold, unmodified from the official Liberation Fonts
2.1.5 binary release. The family provides metric compatibility with Arial.

- Project: https://github.com/liberationfonts/liberation-fonts
- Release: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
- Archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz

the same archive. License: SIL Open Font License 1.1. Copyright notices are kept
