Проверенные официальные разделы

Параметры и опорные формы

About Parameters: параметр задаёт конкретное движение, а формы между его опорами интерполируются. Руководство различает минимум, значение по умолчанию и максимум; устойчивые ID помогают повторно использовать движение. Для Motif это основание связывать множество деталей с небольшим числом именованных параметров.

Add/Delete Keys to/from Parameters: опорные формы создаются для выбранного объекта и параметра, в том числе сразу в двух или трёх положениях. В Motif кнопка создания параметра сетки готовит три опоры; явная правка опоры остаётся отдельной от записи текущего кадра. Добавление произвольных позиций и управление ими стоит развивать дальше.

Parameter Palette: параметры объединяются в группы, могут фильтроваться по выбранным объектам; палитра предоставляет компактные средства изменения значений. В Motif это ориентир для группировки и поиска нужных органов управления. Разбиение нашего контекстного инспектора на категории свойств — собственное применение этого принципа, а не описание интерфейса Cubism.

Деформеры и иерархия

Warp Deformer: общая область деформирует несколько дочерних объектов. Руководство отдельно рассматривает деления вычисляемого преобразования и деления редактируемой структуры Безье; это разные настройки. Нынешние девять точек Motif не следует считать эквивалентом настройки «3×3» Cubism. У Motif пока фиксированная квадратичная сетка смещений 3×3.

Parent-Child Hierarchy Structure: изменение родителя передаётся потомкам, а локальная правка потомка не изменяет родителя. В Motif иерархия «голова → черты лица → глаз» позволяет новой детали наследовать подготовленное движение. Контуры и вложенные сетки вычисляются с учётом этой иерархии; состав групп остаётся редактируемым.

Сочетания параметров

Keyforms: Make X, Y Movements: сочетание двух параметров с тремя опорами у каждого даёт девять сочетаний форм. Объединённый двумерный контроллер показывает эту таблицу, но сам по себе её не создаёт. Для Motif следующий шаг — представлять такие сочетания явно; последовательное наложение двух независимых сеток не заменяет авторскую поправку в диагональной позе.

Automatic Generation of Four Corner Forms: диагональные формы можно получить из подготовленных основных направлений и затем исправить вручную. Повторная генерация способна заменить ручные поправки. В Motif это будущая операция с предпросмотром результата, Undo и явным выбором заменяемых форм, а не скрытое перерасчитывание рисунка при проигрывании.

Маски и движение во времени

Clipping Mask: форма одной детали ограничивает видимость другой, например радужка остаётся внутри глаза. Руководство отдельно предупреждает о неверных связях, неполных диапазонах опор и различиях отображения при экспорте. В Motif маска сейчас задаётся первым дочерним контуром группы clip. Проверяем её одновременно с деформируемыми деталями на крайних и промежуточных позах.

Timeline Palette: анимация задаёт изменение параметров и свойств по времени; ключи можно рассматривать на таймлайне и как кривые. Для Motif это общий механизм клипов для персонажей и UI. Опорные формы рига остаются общими данными, а изменение их параметра во времени принадлежит клипу.

Create a Form Animation: форму объекта можно менять прямо на текущем кадре, а движение между ключами интерполировать. Руководство отличает такую правку от изменения структуры модели. В Motif этому соответствует рисование узлов контура на выбранном кадре с записью отдельной формы. При этом одна поза доступна во всех рабочих пространствах, а кости и векторные инструменты остаются частью общего редактора.

Правила применения в Motif

  1. Свободное векторное рисование. Деформер меняет вычисляемую позу; исходные кривые остаются доступны. Формы можно подготовить как ответы параметра либо нарисовать в конкретном кадре.
  2. Общий кадр. Пространства меняют инструменты и раскладку панелей. Выбранные клип и время общие для рисунка, настройки и анимации, включая UI. Опорная форма всегда обозначается отдельно.
  3. Объём требует согласованных признаков. Направление носа, смещение черт, сжатие дальней стороны, силуэт щеки и перекрытие волос должны описывать один поворот. Сам факт наличия сетки не создаёт убедительный объём. Это вывод для нашего процесса подготовки, а не дополнительное правило формата Cubism.
  4. Прямые правки допустимы. Прямой ключ детали имеет приоритет над её связью параметра. Художник может двигать объект в Рисовании и рисовать ключевые кадры; согласованность рига проверяется в готовых клипах.
  5. UI остаётся самостоятельной задачей. Слои, раскладка, текст, стили, состояния Hover/Press/Disabled и экспорт UI используют существующие механизмы Motif. Персонажу не требуется подменять общую модель документа.

Мы заимствуем проверенные приёмы подготовки и управления рисунком, реализуя собственные алгоритмы для векторных сцен MSC. Этот каталог не заявляет совместимость с форматами проектов или SDK Cubism.
