SVG и Web assets

Один и тот же нативный экспортёр работает из редактора и CLI. Сторонний Python-конвертер не нужен. Примеры: examples/web-assets.msc и examples/web-effects.msc.

Из редактора

  1. Откройте «Экспорт → Токены, темы и метаданные…».
  2. Свяжите цвета палитры с currentColor или --имя. Впишите ID, путь, вариант, профиль и необходимые точки.
  3. «Применить к .msc» создаёт один шаг Undo. Сохраните файл обычным Ctrl+S.
  4. «SVG холста…» сохраняет активный холст. «Web-пакет…» учитывает выбор всех холстов в окне экспорта.
  5. Откройте index.html в папке пакета: темы, фон, 100%/200%, повтор тайлов 3×3, растягиваемый 9-slice и выбор анимации.

«Тема холста (просмотр)» меняет отображение активного холста, не переписывая цвета сцены. Экспорт использует авторские цвета как запасные значения CSS. Для иллюстрации с фоном нарисуйте фон отдельным прямоугольником: фон артборда и подложка в SVG не входят.

В разделе «Темы» можно добавить любое допустимое имя (например, dark, warm, high-contrast), выбрать цвет визуально или ввести HEX. Метаданные сохраняются и у сцен с 3D/физикой: проверка возможностей SVG происходит только при экспорте. Ключевые слова разделяются запятыми.

Командная строка

motif svg examples/web-assets.msc --board "ui-leaf.24" -o leaf.svg
motif web examples/web-assets.msc -o web-output
motif web scene.msc --profile icon24 --strict -o checked-assets

Без --board экспортируются все холсты. В команде svg для одного холста -o — имя файла, для нескольких — папка. web всегда пишет папку. Она содержит SVG, tokens.css, animations.css, graphics.json и index.html. Повторный экспорт заменяет одноимённые файлы; устаревшие файлы после переименования ассетов не удаляются автоматически.

Сначала проверяется весь пакет. Ошибка геометрии, метаданных, повтор ID/пути или неподдерживаемый эффект останавливает запись. Предупреждения попадают в stderr и манифест. --strict превращает все предупреждения в отказ до записи. Ошибки диска могут оставить часть файлов обновлённой: атомарна замена отдельного файла, не всей папки.

Токены и темы

let ink = #2b2620
let accent = #628f47
path leaf d "M 4 20 Q 3 4 20 4 Q 20 20 4 20 Z" fill accent stroke ink 1.75

Связь ink → currentColor даёт наследование цвета текста. accent → --icon-accent даёт var(--icon-accent,#628f47). HEX-литерал такого же цвета остаётся литералом: замена основана на ссылке на палитру. Сохраняются также ссылки в остановках градиента. Локальные параметры символов, не разрешённые в имена общей палитры, экспортируются вычисленным цветом.

Подключите оба CSS-файла и вставьте SVG непосредственно в HTML. Переменные страницы не наследуются через <img src="…svg">. У контейнера задайте data-theme="dark". Имена тем, переменных и классов ограничены безопасными ASCII-идентификаторами. Разные палитры не могут присвоить одной CSS-переменной разные значения в одном пакете.

9-slice в галерее использует border-image, поэтому показывает запасные цвета самого SVG. Это отдельный контекст от тематизируемых inline-превью.

Метаданные в .msc

Редактор хранит одну JSON-строку // @motif-web {...} до первого artboard, в общем заголовке файла. Старые версии Motif видят обычный комментарий и открывают сцену. Правка через окно настроек участвует в Undo/Redo.

// @motif-web {"tokens":{"ink":"currentColor","accent":"--icon-accent"},"themes":{"dark":{"ink":"#eee8db","accent":"#a5c77e"}},"assets":{"ui-leaf.24":{"id":"ui-leaf","file":"icons/ui-leaf.24.svg","profile":"icon24","variant":"default","stage":"draft","keywords":["leaf"],"pivot":[12,12],"layers":{"leaf":{"class":"base anim-leaf"}}}}}

Ключ assets — точное имя холста. Поля ассета: id, относительный file, profile, variant, stage, keywords, pivot, hotspot, slices, manual_fix, layers, metadata. Поле metadata хранит произвольные проектные данные (слоты, маски тайлов, описание рига). Пара id + variant должна быть уникальной; один id может иметь варианты 16, 24, 48. Неизвестные поля считаются ошибкой, чтобы опечатки не теряли данные. Отсутствующие поля получают значения по умолчанию.

Pivot/hotspot ассета заданы в координатах viewBox; slices — сверху, справа, снизу, слева. У каждого слоя в манифесте есть локальный pivot, матрица, родитель, исходный и SVG ID, собственный slice. Метаданные не меняют рисунок. ID слоя получает префикс пути файла; class сохраняется без префикса. При отсутствии class используется имя слоя, если оно состоит из допустимых CSS-классов.

Русские имена и имя для экспорта

Слои и холсты можно называть по-русски. В SVG id, class и имена файлов пишутся латиницей. Русские буквы переводятся транслитерацией: холст «Нужда: еда» даёт файл Nuzhda-eda.svg, слой щека — id …-node-shcheka. Пробелы и знаки препинания становятся дефисом. Само русское имя слоя остаётся в файле атрибутом data-name="Щека".

Своё латинское имя задаётся в поле «Имя для экспорта» под названием выбранного слоя на панели «Свойства». Подсказка в пустом поле показывает транслитерацию, которая будет без него. Поле пишет layers.<id>.id в метаданные холста одним шагом Undo. Допустимы латиница, цифры, _ и -, первая — буква. Два слоя одного холста не могут получить одно имя. То же поле и CSS class слоёв есть в окне «Токены, темы и метаданные…».

Анимация

Все исходные дорожки, ключи, кривые и события записываются в graphics.json. Для обычных перемещений, поворота, масштаба, skew, прозрачности, цвета заливки, цвета и толщины обычной обводки создаётся CSS: data-motion="Имя" на контейнере запускает соответствующую анимацию. Точное значение selector берите из манифеста: имена нормализуются.

CSS сэмплирует движение 60 раз в секунду и добавляет исходные моменты ключей; сложные кривые приближённые между выборками. Конечный ключ цикла сохраняется отдельно от начала. Pivot учитывается в матрице. prefers-reduced-motion: reduce возвращает исходный статический рисунок. Дорожки формы и параметров эффектов, физика, IK/скининг, кипение кисти и анимации длиннее 60 секунд остаются данными с предупреждением; готовый CSS для них не заявляется. События в CSS не исполняются.

Фигуры с эффектами поддерживают CSS-перемещение и прозрачность, включая проявление из нуля. Поворот/масштаб/skew эффектов, движение детей внутри размытой группы и цветовые дорожки фактурных фигур сохраняются в JSON с предупреждением: фиксированные векторные проходы не могут точно повторить такие изменения. Цветовые ключи — вычисленные авторские HEX; тема не переопределяет их во время анимации.

Профили и проверки

ПрофильПроверка
generalКорректные размеры, ID, пути, ссылки, slice и поддерживаемые свойства.
icon16 / icon24 / icon48Точный размер холста; предупреждения для толщины 1.5 / 1.75 / 2 px, градиента, дополнительных эффектов и бюджета 2 КиБ. Icon16 также проверяет монохромность и сетку 0.5 px, включая контрольные точки кривых.
tileБюджет 8 КиБ; галерея с повтором 3×3.
illustrationБюджет 60 КиБ.

Профили не перерисовывают ассет и не обещают художественную оценку: читаемость, контраст на конкретном интерфейсе и стыковку разных переходных тайлов проверяют в контексте. В галерее показан повтор одного тайла, а не полный набор соседних масок.

Поддержка и границы

SVG сохраняет иерархию групп, контуры и примитивы, матрицы, fill/stroke, alpha, cap/join/dash, линейные и радиальные градиенты, простую clip-маску, shadow/elevation, glow, inset, noise, дополнительные outlines и процедурные кисти (rough, hatch, grain, bands). Blur работает у фигур и групп, включая неравномерный масштаб, skew и вложенные маски. Текст выгружается контурами шрифта. В SVG нет script, style, text, image, foreignObject, внешних ресурсов и фиксированных width/height на корне. Числа геометрии округляются до двух знаков, коэффициенты матриц — до шести.

Эффекты используют те же векторные операции, что и штатный рендер. Фильтры считают радиусы и смещения в координатах холста; шум и кисти становятся контурами, поэтому SVG с плотной фактурой может быть большим. Производные цвета фактур и ступенчатых градиентов запекаются в HEX, основные заливки сохраняют связь с токенами. Gaussian blur браузера и приближённое размытие Motif могут немного различаться.

Режимы blend, объёмные тела, орбиты, частицы, мягкие тела, жидкости и верёвки останавливают экспорт с именем слоя и свойства. Они продолжают работать в PNG и Motif runtime. Clip с группой вместо фигуры-маски и вырожденные трансформации эффектов не поддерживаются. Экспорт не маскирует эти ограничения растровой картинкой.

В штатном рендере также исправлены границы blur: толстая обводка при сильном неравномерном масштабе больше не обрезается границами слоя.

Комплектность обновления

Свежий комплект содержит согласованные справку и примеры: UI-kit с семью холстами, machine со step/push/land, отдельную папку godot-addon. Обновление теперь восстанавливает godot-addon, даже если версия программы не изменилась. Пользовательские примеры обновлятор сохраняет: если старый examples отличается от справки, возьмите соответствующий пример из свежего архива, сохранив свою копию отдельно.
