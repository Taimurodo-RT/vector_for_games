Скрипт сцены (.msc)

Новое: сетки deform, формы контура, ключи появления и общий кадр.

Сцена Motif — это короткий текст. Одна строка описывает один объект: тип, имя и свойства. Текст можно писать вручную, а можно рисовать мышью и смотреть, как он пишется сам.

Панель скрипта находится рядом с холстом:

  • каждое изменение текста сразу перерисовывает сцену;
  • клик по строке выбирает объект, а строки выбранного объекта подсвечены;
  • пока в тексте есть ошибка, на холсте остаётся последняя рабочая версия, а строка с ошибкой подсвечена красным и объяснена по-русски;
  • F1 или «?» в заголовке панели открывает шпаргалку, Ctrl+E сворачивает панель.

Как устроена строка

ellipse ball "Мяч"  at 150 150  size 72  fill #ff5a36  stroke #1b1d24 4
│        │    │       └─ свойства: слово и значения, в любом порядке
│        │    └─ имя для панели слоёв (можно не писать)
│        └─ id: по нему объект находят анимации и игра
└─ тип объекта

Типы объектов: rect, ellipse, star, polygon, path, text, group. Комментарии начинаются с // или с # в начале строки.

Полный пример

artboard "Главный" 480x360 bg #fff4e4

let ink = #1b1d24

ellipse ball "Мяч"  at 150 150  size 72  fill #ff5a36  stroke ink 4
star    star        at 340 150  size 130 points 5  fill #ffc531

group coins at 36 40 {
  for i in 0..5 {
    ellipse coin{i} at {i * 28} 0 size 16 fill #ffd23f
  }
}

anim Idle 1.2s loop {
  ball.y   0: 120 ease-in | 0.6: 278 ease-out | 1.2: 120
  star.rot 0: 0 linear | 1.2: 72
}

Версия форматаmotif 1Первая строка файла. Motif пишет её сам при сохранении. Файл без неё — старый, он открывается как версия 1 и при сохранении получает строку. Motif ставит наименьшую версию, которая читает файл: сцена без направляющих остаётся motif 1, с ними — motif 2, с живой операцией (group … combine) — motif 3, со стилями (style), градиентами палитры или темами (theme) — motif 4, с вариантами символа (variant) — motif 5. Файл более новой версии, чем понимает ваш Motif, не открывается: обновите Motif. Игры (Forge) принимают только файлы с этой строкой. Старые файлы, которые обязаны открываться всегда, лежат в tests/old-formats/.

Motif дописывает id сам при сохранении всему, у чего его ещё нет, и сохраняет при переименовании: speed можно переименовать в скорость, и привязка в игре не порвётся. Символы

Символ — это кусок сцены, который рисуют один раз, а вставляют много раз: монета, кристалл, кнопка, мяч. Поменяли символ — поменялись все копии. У каждой копии свои место, поворот, масштаб и параметры.

symbol Coin size=28 color=#ffd23f {
  ellipse rim  size {size} fill #d99a1e stroke ink 3
  ellipse face size {size * 0.72} fill color
}

use Coin c1 at 60 44
use Coin c2 "Большая" at 140 44 size=44 color=#c9d1e0 rot 15

anim Idle 1s loop {
  c2.rot      0: 0 linear | 1: 360
  c1-face.sx  0: 1 | 0.5: 0.2 | 1: 1
}
ЧтоЗаписьПояснение
Символsymbol Имя имя=значение … { … }Пишется на верхнем уровне. Сам по себе не рисуется. Параметры — числа или цвета со значением по умолчанию, внутри символа это обычные переменные: size {size}, fill color.
Маскаsymbol Ball clip size=64 { … }Первый объект каждой копии обрезает остальные: рисунок на мяче виден только внутри мяча и сжимается вместе с ним.
Копияuse Имя id ["имя"] свойства параметрыКопия — это группа: at, rot, scale, opacity, blur и другие свойства группы, плюс имя=значение для параметров. Незаписанные параметры берутся по умолчанию.
Объекты копииc1-faceid копии, дефис, id внутри символа. По нему анимируют и правят одну копию.
В циклеfor i in 0..6 { use Coin coin{i} at {i * 40} 0 }Копии можно ставить циклом и в группы.
Вариантvariant main face=accent hide iconСтрока внутри symbol: именованный набор значений параметров и объектов символа, которые вариант скрывает (hide) или показывает (show). Подробнее ниже.
Копия-вариантuse Button b2 at 40 90 variant mainКопия берёт вариант символа. Параметр, записанный у самой копии, сильнее варианта.

Блок symbol правится и мышью: двойной щелчок по копии в «Рисовании» открывает символ, и правки внутри пишутся в его строки, то есть меняют все копии (подробнее). Правка объекта копии только для неё самой (например, сдвиг c1-face при включённом «только эту копию» или ключ анимации) записывается в override или в клип и остальные копии не трогает. Подробнее о работе с символами в редакторе — на странице «Панель свойств».

Варианты символа

Вариант — это один и тот же символ в другом виде: кнопка обычная, главная и с одной иконкой. Рисунок у вариантов общий, отличаются значения параметров и то, какие детали показаны. Поправили символ — поправились все варианты.

let accent = #ff5a36
symbol Button face=#ffffff text=#1b1d24 {
  variant main face=accent text=#ffffff
  variant icon hide label
  variant fresh show badge
  group row stack row center gap 8 pad 12 {
    rect bg fit r 10 fill face
    star glyph size 16 fill text
    text label content "Играть" font-size 16 fill text
  }
  ellipse badge at 50 -20 size 14 14 fill accent hidden
}
use Button plain at 90 80
use Button play at 260 80 variant main
use Button star at 420 80 variant icon
use Button buy at 260 200 variant main face=#2d6cdf
use Button fresh at 90 320 variant fresh
  • Значения. После имени варианта идут параметр=значение. Порядок такой: значение по умолчанию из строки symbol, поверх него значение варианта, поверх него то, что записано у самой копии. В варианте значением может быть имя палитры (face=accent), поэтому темы меняют и варианты; в умолчаниях символа имена палитры не пишутся.
  • Скрытые детали. После hide идут id объектов символа, которых у этого варианта нет. Скрытая деталь не занимает места в раскладке stack: кнопка без подписи сама становится уже.
  • Показанные детали. После show идут id объектов, которые в самом символе записаны со свойством hidden. Такой детали нет ни в одной копии, пока вариант её не покажет: метка «новое», замок, лента «хит». Добавили в символ новую скрытую деталь — готовые копии не изменились, деталь появится только там, где вариант её показывает.
  • Копия без слова variant рисуется как сам символ. Вариант у копии один.
  • Ошибки. Имя варианта, которого у символа нет, неизвестный параметр и объект после hide или show, которого нет в символе, показываются с подсказкой. Один объект нельзя и скрыть, и показать в одном варианте.

Файл с вариантами сохраняется как motif 5. Игре вариант ничего не стоит: он применяется при чтении скрипта, как стиль. Работа с вариантами в редакторе — в разделе «Панель свойств».

Стили

Стиль хранит вид под именем. Он пишется одной строкой на верхнем уровне, а объект берёт его словом style на своей строке. Поменяли строку стиля — изменились все объекты, которые его берут. Пример — examples/styles.msc.

let ink = #1b1d24
style card fill #ffffff stroke ink 2 r 14 shadow 0 6 12 #00000033
rect card1 at 100 110 size 150 160 style card
rect card2 at 260 110 size 150 160 style card fill #fff4c2
rect card3 at 420 110 size 150 160 style card no shadow
ЧтоЗаписьПояснение
Стильstyle имя свойства…Одна строка на верхнем уровне, выше или ниже объектов. Имя — одно слово без кавычек. Строка выше первого artboard общая для всех холстов файла.
Что хранит стильfill, gradient, stroke, stroke-gradient, dash, cap, join, outline, opacity, blend, r, shadow, inset, glow, blur, noise, elevation, rough, boil, bands, hatch, grain, seed, font, font-size, letter-spacing, line-height, alignТолько вид. Место, размер, контур, кости, физика и роль в интерфейсе остаются на строке объекта. Значения пишутся как у объекта, цвета палитры работают по имени (fill paper).
Объект берёт стильrect a … style cardРаботает у любых объектов, в группах, циклах и символах. Объект берёт из стиля то, что у него бывает: прямоугольник не возьмёт шрифт, группа не возьмёт кисть.
Своё поверх стиля… style card fill #fff4c2Свойство на строке объекта главнее стиля. Своя заливка fill заменяет и градиент стиля, своя обводка stroke заменяет градиент обводки.
Отказ от свойства… style card no shadowОбъект не берёт это свойство из стиля: тени у него нет, даже если она есть в стиле.

Стиль применяется, когда скрипт читается: в документе, в картинке и в игре это обычные объекты, поэтому анимация, override и экспорт работают как раньше. Стиль не берёт другой стиль. Работа со стилями в редакторе — на странице «Панель свойств».

Градиенты палитры

Цвета, названные строками let на верхнем уровне, составляют палитру. Градиент хранится в ней так же, под именем, а объект берёт его словом gradient или stroke-gradient. Поменяли строку let — изменились все объекты, которые берут градиент. Пример — examples/palette.msc.

let gold = #ffd23f
let ember = #ff5a36
let sunset = linear 90 gold ember
let halo = radial #fff8ea gold ember
style badge gradient sunset r 12
ellipse sun at 110 190 size 90 90 gradient halo
rect frame at 260 190 size 120 80 stroke #1b1d24 6 stroke-gradient sunset
ЧтоЗаписьПояснение
Градиент палитрыlet имя = linear угол цвет цвет…, let имя = radial цвет цвет…То же, что пишется после gradient: вид, угол линейного и от двух цветов. Цвета могут быть именами палитры. Строка стоит на верхнем уровне и выше объектов, которые берут градиент. Имя не совпадает с именем цвета.
Объект берёт градиентgradient sunset, stroke-gradient sunsetОдно слово после свойства — имя градиента палитры. Работает на строке объекта и в стиле.

Файл с градиентом палитры сохраняется как motif 4. В редакторе градиенты палитры, «Заменить везде» и «Собрать в палитру» описаны в разделе «Свойства и оформление».

Темы

Тема даёт именам палитры и стилям другие значения. Сцена записана один раз, а показывается, выгружается и играет в любой из тем: светлый и тёмный набор кнопок, летний и зимний тайл, обычный и праздничный значок живут в одном файле. Пример — examples/themes.msc.

let paper = #f4efe6
let main = #3b6cff
let radius = 14
let face = linear 90 #6f93ff main
style sheet fill #ffffff stroke #1b1d24 3 r radius

theme night {
  paper = #14161f
  main = #7c5cff
  radius = 8
  face = linear 60 #a48bff #3d2a99
  style sheet fill #232838 stroke #0a0c12 3 r radius glow 14 #7c5cff55
}

artboard "Кнопки" 560x330 bg paper
ЧтоЗаписьПояснение
Темаtheme night { … }Блок на верхнем уровне сцены. Скобка { стоит в конце строки, каждая запись — на своей строке. Одну тему можно писать в нескольких блоках (общая часть файла и холст): они складываются.
Цвет или числоpaper = #14161f, radius = 8Другое значение имени, которое названо строкой let на верхнем уровне. Цвет остаётся цветом, число — числом.
Градиентface = linear 60 #a48bff #3d2a99Другой градиент палитры под тем же именем. Вид (линейный или радиальный) может быть другим.
Стильstyle sheet fill #232838 r radiusСтрока стиля в теме заменяет строку стиля целиком: свойства, которых в ней нет, из исходной строки не берутся.
  • Тема пишет только то, что в ней другое. Остальные имена остаются как в сцене.
  • Значение темы встаёт на место строки let или style, поэтому за темой идёт всё, что берёт имя: объекты, стили, градиенты палитры, ключи анимации с именем цвета, фон холста.
  • Тема не добавляет имён и объектов. Запись с именем, которого нет в палитре или в стилях, — ошибка; сообщение называет имена, которые есть.
  • Ошибка в любой теме видна сразу, какая бы тема ни была показана.
  • Тема — выбор того, кто показывает сцену: редактора, командной строки (--theme night) или игры (set_theme, см. «Рантайм»). В файле не записано, какая тема «текущая». Без выбора сцена показана как записана.

Файл с темой сохраняется как motif 4. Работа с темами в редакторе — в разделе «Свойства и оформление», выгрузка — на странице «Экспорт».

Анимации

anim Имя 1.2s [loop] {
  объект.свойство  время: значение [кривая] | время: значение [кривая] | …
  event имя время время … [ключ=значение …]
}

Строка event — событие для игры: имя одним словом и одно или несколько времён в секундах, в пределах анимации (event step 0 0.2). У одной анимации каждое имя пишется одной строкой.

После времён — данные, которые игра получает вместе с событием: event hit 0.3 damage=2 crit=true side=left say="ой, больно". Значение — число, true/false, слово или строка в кавычках; ключ в строке один раз, id занят скрытым id. Данные общие для всех времён строки. Без скрипта их задают на таймлайне: правый клик по флажку → «Данные для игры» (как). Когда событие двигают или переименовывают на таймлайне, данные остаются как написаны. В игре: Event::get("damage") в motif-runtime, сигнал event_data(имя, словарь) у MotifSprite, поле data у событий в договоре сцены. Запечённая выгрузка в Godot передаёт только имя.

Объект с именем event по-прежнему анимируется как event.x ….

Время — в секундах от начала анимации. Кривая после значения действует до следующего ключа, по умолчанию это ease-in-out. Имена свойств в анимации:

x y w h rot sx sy kx ky opacity r points inner fill stroke stroke_w, у текста ещё font-size letter-spacing reveal wave phase, для эффектов blur elevation shadow-x shadow-y shadow-blur glow inset-x inset-y inset-blur noise.

Формулы и override

Если значение задано формулой или циклом (например, at {i * 28} 0), редактор не трогает формулу при правке мышью. Вместо этого он дописывает правку в блок override в конце файла:

override {
  coin2.y = 12
}

Так формулы остаются формулами, а ручные правки видны отдельно. Строку из override можно удалить, и объект вернётся к значению по формуле.

Свой текст у копии. У текста внутри символа или цикла строка одна на все копии, поэтому слова одной копии тоже пишутся в override:

symbol Button {
  group row stack row center pad 12 {
    rect bg fit r 10 fill #2d6cdf
    text label content "Играть" font-size 16 fill #ffffff
  }
}
use Button play at 90 60
use Button buy at 90 120
override {
  buy-label.content = "Купить всё"
}

Кнопка play говорит «Играть», как символ, а buy — «Купить всё», и её фон в раскладке stack сам становится шире. В редакторе это делается без скрипта: выделите текст копии и напишите новые слова в поле «Текст» (подробнее). В примере examples/variants.msc так подписаны кнопки «Купить» и «Назад». Файл с такой строкой сохраняется как motif 5.

Сцена — обычный текст. Файлы .msc удобно хранить в git рядом с игрой: в истории видно, какое число поменялось. Их можно генерировать скриптами и проверять командой motif check.
