Диагностика сцен кодом

Команда inspect извлекает данные сцены в JSON через ядро Motif. Она позволяет сравнивать исходник с вычисленной позой, искать неверные связи и проверять геометрию без управления окном редактора.

Версия схемы — 1. Данные читаются из сохранённого MSC. Несохранённая поза открытого редактора в отчёт не попадает. Команда не меняет исходник; попытка записать отчёт поверх входного файла отклоняется.

Команды

motif inspect character-anime.msc
motif inspect character-anime.msc --anim Expressions --time 1 --node head
motif inspect character-anime.msc --board 1 --anim Expressions --time 1 -o C:/Users/taimu/OneDrive/Документы/ClaudeWorld/VectorEditor-Lab/runs/2026-10-29-face/reports/face.json

Без -o стандартный вывод содержит только JSON и завершающий перевод строки. С -o вывод записывается в указанный файл, отсутствующие родительские папки создаются; стандартный вывод пуст. Ошибки идут в stderr и возвращают ненулевой код завершения. Существующий файл отчёта заменяется, поэтому для сохранения предыдущих измерений выбирайте новую папку запуска.

--board принимает имя или номер с 1. Без выбора холста отчёт содержит все холсты, подходящие под фильтры. --anim вычисляет позу клипа на --time в секундах с обычными правилами цикла, интерполяции и симуляции Motif. Без клипа показывается статическая вычисленная поза; само значение времени не запускает анимацию. --side дополнительно применяет сторону существующего набора directions. Как у команды render, при наличии Walk_up запрос --anim Walk --side up использует этот специальный клип; иначе берётся общий Walk. Поле pose_selection.resolved_clip каждого холста показывает фактически выбранный клип.

--node ID оставляет в массивах узлов выбранный объект и его потомков. Параметры, связи, клипы и исходник холста остаются полным контекстом: связь отфильтрованного объекта может зависеть от узла вне поддерева. Родитель ID также может находиться за пределами выборки. Несуществующие ID, клипы или холсты дают ошибку; время должно быть конечным и неотрицательным.

Схема 1

{
  "schema": 1,
  "source": { "path": "character-anime.msc", "encoding": "UTF-8" },
  "selection": { "board": null, "anim": "Expressions", "requested_time": 1.0, "node": "head", "side": null },
  "units": { "length": "artboard_units", "time": "seconds", "angle": "degrees_clockwise" },
  "boards": [{
    "index": 1,
    "name": "Аниме-лицо",
    "artboard": {},
    "source": { "text": "...", "span_unit": "utf8_bytes", "original_segments": [] },
    "base": { "time": 0.0, "nodes": [], "parameters": [], "world": {} },
    "posed": { "time": 1.0, "nodes": [], "parameters": [], "world": {} },
    "drivers": [], "clips": [], "machines": [], "metadata": {}
  }]
}

base содержит данные разобранного документа до выбора клипа и расчёта новой позы. posed — результат общего ядра с параметрами, формами, костями, проекцией и сетками; клип также учитывает свою симуляцию. Это две диагностические копии. Значения по умолчанию, уже применяемые разбором MSC, могут присутствовать в base; неизменённая авторская геометрия находится в geometry.source и в тексте исходника.

Данные узлаСодержимое
id, name, kind, index, parent, children, maskИдентификаторы и иерархия в порядке рисования; index начинается с 0. mask — ID первого ребёнка группы clip.
visible, effective_visible, locked, effective_lockedЛокальное значение и результат с учётом родителей.
propertiesАнимируемые значения по именам MSC: x, y, rot, sx, sy, opacity, fill, warp-x4, contour, visible и другие. Числа — JSON number, цвета — hex-строки, отсутствие краски — null.
local_transform, world_transformШесть коэффициентов [a,b,c,d,e,f]: x′ = ax + cy + e, y′ = bx + dy + f.
local_bounds, world_bounds[x0,y0,x1,y1]. world_bounds включает потомков по правилам ядра. Это геометрические границы путей: они не учитывают тени, толщину обводки или обрезание маской.
geometrysource — исходный путь path; authorable — форма до костей и сеток; rendered — вычисленный локальный путь; world_rendered — тот же путь в координатах артборда; deformed — промежуточный путь skin/симуляции. body_faces отдельно содержит проецируемые грани 2.5D-тела и их края.
lattice, forms, skin, ik, morph, body, orbitРазмеры и девять смещений сетки, контрольные точки, сохранённые формы и текущий индекс, связи костей, bind-матрицы и мазки весов, цели IK, морфинг, глубина и орбиты.
paint, text, layout, ui, physicsГрадиенты, обводки, эффекты, кисть, текст и имя шрифта, раскладка/якоря, роли UI и настройки симуляции. Бинарные шрифты в отчёт не включаются.
sourceМесто объявления, generated, доступность правки значений, spans свойств, текст значений и стилистических атрибутов. Для созданных циклом узлов координаты указывают на общую запись шаблона.

Каждый путь содержит svg, массив elements с операциями M/L/Q/C/Z и координатами точек, а также bounds. У пустого пути границы null. rendered описывает вычисленную геометрию ядра; растровые эффекты, штрихи художественной кисти и пикселизация требуют отдельной проверки рендером.

drivers и clips содержат все дорожки, цели свойств, времена/позиции ключей, значения и ease в синтаксисе MSC. У clips также есть длительность, loop и события. machines раскрывает входы, состояния, переходы и слушателей. metadata содержит каталог персонажей, палитру, положение холста и направления.

Как читать координаты исходника

Все span.start и span.end — полуоткрытые диапазоны байтов UTF-8 внутри boards[i].source.text, не индексы Unicode-символов. Этот текст состоит из общей шапки файла и выбранного артборда. Для нескольких артбордов его смещения могут отличаться от смещений входного файла.

original_segments даёт соответствие частей: local_start, file_start, length. Для смещения внутри сегмента позиция в исходном файле вычисляется как file_start + offset - local_start. Текст уже находится в JSON, поэтому дополнительные чтения исходника для диагностики необязательны.

import json
from pathlib import Path
report = json.loads(Path("face.json").read_text(encoding="utf-8"))
assert report["schema"] == 1
board = report["boards"][0]
face = next(n for n in board["posed"]["nodes"] if n["id"] == "face")
print(face["world_bounds"])
print(face["geometry"]["rendered"]["svg"])
source_bytes = board["source"]["text"].encode("utf-8")
site = face["source"]["site"]["span"]
print(source_bytes[site["start"]:site["end"]].decode("utf-8"))

Рабочие выгрузки отдельно от репозитория

Для этого проекта используйте соседнюю папку VectorEditor-Lab. Каждый разбор помещайте в runs/<дата-задача>/; внутри удобно держать reports для JSON, captures для PNG/GIF, scratch для пробных MSC и cache для временных данных. Путь передаётся явно через -o. Команда не создаёт диагностические выгрузки внутри репозитория сама.

Для сравнения формы используйте inspect вместе с прежними render, frames и check. Числовая проверка помогает локализовать неверную связь; художественную оценку и проверку удобства пользователь выполняет в редакторе. Принципы подготовки персонажа: официальные источники Live2D и решения Motif.
