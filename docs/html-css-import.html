Импорт HTML и CSS

Вставьте короткий HTML-фрагмент и его стили, чтобы получить обычные редактируемые группы, прямоугольники и текст. Разметка задаёт назначение элемента: button становится UI-кнопкой, label — меткой.

Обновлено 29 октября 2026: текстовые теги, переносы, списки и простые элементы форм. Импорт предназначен для отдельных компонентов и коротких панелей, в том числе сгенерированных кодом. Он использует собственный ограниченный конвертер. Фрагмент не открывается в браузере, JavaScript не выполняется, внешние картинки и шрифты не загружаются.

В редакторе

После открытия поле HTML получает фокус. В каждом поле работают Ctrl+V, кнопка «Вставить HTML/CSS» и правый клик → «Вставить». Вставка заменяет выделенный текст; содержимое HTML и CSS независимо. Кнопки запрашивают текст из системного буфера и возвращают фокус нужному полю.

Многострочная вставка сохраняет табы и переносы HTML/CSS. Tab добавляет отступ внутри поля, Shift+Tab убирает его. Отступы между HTML-блоками не создают пустых строк в рисунке. В pre и при white-space:pre сохраняются строки и пробелы; табы разворачиваются до следующей колонки tab-size (по умолчанию 8, поддерживаются значения 1–16).

Откройте импорт HTML/CSS из меню «Файл». Вставьте разметку в поле HTML, стили в поле CSS; встроенный блок style тоже читается. Выполните преобразование и просмотрите результат и предупреждения. Кнопка «Преобразовать» показывает превью и предупреждения. «Добавить UI-холст» добавляет результат в текущий документ отдельным холстом, сохраняя прежние сцены и анимации. Весь импорт отменяется одним Undo; фон, текст и группы остаются редактируемыми.

Пример находится в examples/import/button.html и button.css. В нём две кнопки со штатными Hover, Press, Disabled и Focus. Проверяйте их через «Проверить», таймлайн или правый предпросмотр.

Второй пример: text-elements.html и text-elements.css. Это полный документ с табовыми отступами, форматированным текстом, списками, фрагментом кода и полями интерфейса.

Командная строка

motif import-html button.html --css button.css -o button.msc
motif check button.msc
motif render button.msc -o button.png
motif render button.msc --anim Hover --time 0.2 -o button-hover.png

Без -o команда пишет только MSC в stdout. Предупреждения идут в stderr. С -o создаются родительские папки и записывается новый файл; попытка записать поверх входного HTML или CSS отклоняется. Файл стилей указывается явно: link href не загружается. Для автоматизации доступна функция motif_html::import(html, css), возвращающая source, warnings и elements.

Поддерживаемая часть

  • Контейнеры div, main, section, article, header/footer, nav/aside и простые семантические блоки. Фрагменты и полные документы с doctype/html/head/body читаются; служебные title/meta не попадают в рисунок. Иерархия сохраняется в группах, ID приводятся к допустимому уникальному имени.
  • Текст: h1–h6, p, span, label, strong/b, em/i, u/ins, s/del, small, sub/sup, code/pre и a. br делает настоящий перенос; hr становится разделителем; ul/ol/li получают маркеры и нумерацию. Сущности HTML, Unicode и кавычки сохраняются; буквальное \n в тексте кода отличается от настоящего переноса.
  • Селекторы тегов, #id, .class, их сочетания, списки через запятую, потомки и непосредственные дети >, :root и [disabled]. Учитываются специфичность, порядок деклараций, inline style и !important.
  • Цвета #RGB/#RGBA/#RRGGBB/#RRGGBBAA, rgb/rgba, основные имена цветов, currentColor и прозрачность. Наследуются цвет, размер, начертание и интервалы текста. CSS-переменные var с простым fallback наследуются; циклы и отсутствующие значения отмечаются.
  • width/height, padding/margin по четырём сторонам, gap, content-box/border-box. Единицы px, em и rem; число без единицы разрешено для нуля. Размеры текста измеряются встроенным шрифтом Motif.
  • Поток блоков и строковых элементов, выравнивание текста по базовой линии, явные br, display:flex, flex-direction row/column, align-items/justify-content center или flex-start. Это вычисленные позиции; flex-grow, wrapping, grid и автоматический перенос по ширине не реализованы.
  • Заливка, равномерный радиус, сплошная рамка, линейный градиент без позиционных стопов и одна внешняя тень без ненулевого spread. Размер шрифта, font-weight, line-height, letter-spacing, text-decoration и white-space. Наклонный текст передаётся редактируемым скосом. Используется встроенный IBM Plex Sans; code/pre и внешняя font-family предупреждают о замене шрифта.
  • :hover → Hover, :active → Press, :disabled → Disabled, :focus/:focus-visible → Focus. Цвет, обводка, радиус и прозрачность превращаются в штатные ключи. Press включает применимые hover-правила. В этой версии переходы имеют длительность 0.2 с; CSS transition не переносится.

Простые элементы интерфейса

HTMLРезультат Motif
button; input button/submit/resetUI Button с текстом и редактируемым фоном.
input text/search/email/url/tel/number/passwordUI Input, подпись из value или placeholder; пароль показан скрытыми символами.
input checkbox/radioUI Check с отдельными частями checked/unchecked. Radio рисуется круглым; группировку выбора задайте в игре.
input rangeUI Slider с частями track/grabber и начальным положением из min/max/value.
textareaРедактируемый многострочный рисунок, UI Input; поведение многострочного ввода следует настроить в игре.
select/optionUI Option с выбранной подписью и стрелкой; список вариантов и его поведение следует заполнить в игре.

Элементы форм передают графическую основу и существующие UI-роли Motif. Проверка HTML-форм, отправка данных, связь label/for, переход по href и обработчики событий не создаются. Конвертер перечисляет ограничения в предупреждениях.

Составная подпись с несколькими span/b/другими текстовыми фрагментами сохраняется целиком в векторном рисунке. Штатный экспорт screen/kit использует первый текстовый part как подпись контрола; многоцветный или смешанный текст для игрового контрола требует доработки. Импорт предупреждает об этом ограничении.

Что требует ручной доработки

Неподдерживаемые селекторы, свойства, единицы, внешние ресурсы и обработчики событий перечисляются в предупреждениях. Для at-rule, псевдоэлементов, transform, filter, URL-заливок, сложных радиусов, нескольких теней и адаптивной раскладки нужны дополнительные средства. Разные радиусы углов упрощаются до первого; 50% превращается в равномерную «пилюлю» с предупреждением. Изменение размеров или градиента/тени в псевдосостоянии не переносится и явно отмечается. Сброс градиента цветом через background в обычном состоянии поддержан; если такой сброс требуется в :hover, остаётся базовый градиент с предупреждением, ложный цветовой ключ не создаётся. Многострочный вложенный inline-блок приближённо считается единым прямоугольником, о чём выдаётся предупреждение. Атрибут disabled задаёт базовый вид, но недоступность поведения следует задать в проверке UI или игре.

HTML трактуется как ограниченное дерево фрагмента с простым восстановлением незакрытых тегов. Оно не заменяет алгоритм DOM браузера для ошибочной вложенности. Обычные блоки не получают автоматическую браузерную ширину окна; задавайте размеры и flex-направление явно. Пределы: до 200 КБ HTML и CSS по отдельности, 2048 узлов и 2048 правил, глубина до 64, размер до 8192 единиц. Результат проверяется парсером MSC перед выдачей.

Как готовить код генератором

Попросите отдельный компонент без JS: явный button, простые вложенные div/span, размеры в px, именованные классы, ограниченный flex, обычные цвета, радиусы и рамки. Сначала конвертируйте, затем прочитайте предупреждения и поправьте исходник либо полученную фигуру. Такой процесс позволяет быстро получить редактируемую основу; точность переноса сложного web-компонента нужно оценивать по результату.

Источники логики CSS

Для правил приоритетов использованы CSS Cascading and Inheritance Level 5, для padding/margin — CSS Box Model Level 3, для состояний — Selectors Level 4. Проверено 29.10.2026. Список выше описывает реализованное подмножество Motif, а не полную поддержку стандартов.
