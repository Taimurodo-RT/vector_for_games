Импорт HTML и CSS

Вставьте короткий HTML-фрагмент и его стили, чтобы получить обычные редактируемые группы, прямоугольники и текст. Разметка задаёт назначение элемента: button становится UI-кнопкой, label — меткой.

Обновлено 30 октября 2026: добавлен выбор базовых браузерных стилей Chrome или Firefox. Прозрачность компонента, начальное состояние Normal, переносимые шрифты и внутренняя тень уточнены по браузерному эталону. Поддерживаются позиционированные компоненты, полигональные маски, трансформации, CSS-анимации, текстовые теги и простые элементы форм. Импорт использует собственный ограниченный конвертер. JavaScript не выполняется, внешние картинки и шрифты не загружаются.

В редакторе

После открытия поле HTML получает фокус. В каждом поле работают Ctrl+V, кнопка «Вставить HTML/CSS» и правый клик → «Вставить». Вставка заменяет выделенный текст; содержимое HTML и CSS независимо. Кнопки запрашивают текст из системного буфера и возвращают фокус нужному полю.

Многострочная вставка сохраняет табы и переносы HTML/CSS. Tab добавляет отступ внутри поля, Shift+Tab убирает его. Отступы между HTML-блоками не создают пустых строк в рисунке. В pre и при white-space:pre сохраняются строки и пробелы; табы разворачиваются до следующей колонки tab-size (по умолчанию 8, поддерживаются значения 1–16).

Откройте импорт HTML/CSS из меню «Файл». Вставьте разметку в поле HTML, стили в поле CSS; встроенный блок style тоже читается. Выполните преобразование и просмотрите результат и предупреждения. Кнопка «Преобразовать» показывает превью и предупреждения. «Добавить UI-холст» добавляет результат в текущий документ отдельным холстом, сохраняя прежние сцены и анимации. Весь импорт отменяется одним Undo; фон, текст и группы остаются редактируемыми.

Новый импорт создаёт прозрачный артборд. Подложку предпросмотра можно переключать: «Тёмный», «Светлый» или «Шахматный». Это настройка просмотра; она не добавляет прямоугольник в сцену и не меняет прозрачность экспорта. Белые или светлые подписи удобно рассматривать на тёмной подложке. Явно заданные CSS-заливки элементов при этом сохраняются.

Компонент с псевдосостояниями и без собственной базовой анимации получает первым пустой клип Normal: его рисунок совпадает с исходным видом. Режим «Проверить» начинает с этого вида независимо от выбранного для редактирования клипа Hover и текущего кадра. Наведение запускает Hover и его петлю; после выключения проверки выбранные пользователем клип и кадр сохраняются.

Пример находится в examples/import/button.html и button.css. В нём две кнопки со штатными Hover, Press, Disabled и Focus. Проверяйте их через «Проверить», таймлайн или правый предпросмотр.

Второй пример: text-elements.html и text-elements.css. Это полный документ с табовыми отступами, форматированным текстом, списками, фрагментом кода и полями интерфейса.

Контрольный сложный компонент: uiverse-play.html и uiverse-play.css, исходная кнопка Uiverse.io от Navarog21. Полная присланная разметка сохранена с указанием автора. У кнопки прозрачный фон и светлая надпись; для просмотра подойдёт тёмная подложка. В Normal рамка и углы синие. На самом первом кадре Hover рамка уже зелёная, а углы ещё синие — это предусмотренный CSS вид с задержками и backwards-fill, а не исходное состояние.

Ранее сохранённые MSC с белым артбордом или выбранным Hover автоматически не переписываются. Для нового результата повторите импорт HTML/CSS либо откройте обновлённый пример из новой сборки.

Командная строка

motif import-html button.html --css button.css -o button.msc
motif check button.msc
motif render button.msc -o button.png
motif render button.msc --anim Hover --time 0.2 -o button-hover.png
motif import-html button.html --css button.css --browser firefox -o button-firefox.msc

Без -o команда пишет только MSC в stdout. Предупреждения идут в stderr. С -o создаются родительские папки и записывается новый файл; попытка записать поверх входного HTML или CSS отклоняется. Файл стилей указывается явно: link href не загружается. --browser chrome|firefox разрешён только для import-html; неизвестное имя отклоняется. Без параметра используется Chrome. Для автоматизации доступны motif_html::import(html, css) с базой Chrome и import_with_options(html, css, ImportOptions { browser: BrowserProfile::Firefox }); результат содержит source, warnings и elements.

Базовые стили браузера

В окне импорта выберите Chrome или Firefox перед преобразованием. Профиль задаёт фиксированную основу UA-стилей поддерживаемых тегов: встроенные отступы, рамки, размеры и начертания до применения CSS компонента. Явные авторские правила, inline style и !important перекрывают эту основу по обычному каскаду. Один профиль используется для Normal, Hover/Press/Focus/Disabled и расчёта CSS-анимаций.

UA — встроенные стили браузера. Reset, normalize.css, оформление Uiverse и другие общие стили сайта относятся к авторскому CSS: добавьте их явно, если они нужны для совпадения. Выбор браузера не подгружает эти правила и не проверяет установленный браузер на компьютере. Профили закреплены на снимках исходников от 30.10.2026 и меняются только вместе с реализацией конвертера.

Небольшие различия имеют значение даже при одинаковом компоненте: например, горизонтальный padding кнопки в этих UA-исходниках равен 6 px для Chromium и 4 px для Gecko. Нативный appearance, тема ОС, системные шрифты и специальные контролы переносятся приближённо. Выбор профиля не обещает полного совпадения с любым выпуском Chrome/Firefox или пиксельного воспроизведения платформенных контролов. Ограничения перечисляются при преобразовании.

Для системных контролов используется редактируемая векторная адаптация светлого оформления: checkbox/radio сохраняют видимую рамку, select — отдельную стрелку и место под неё. Их нативный рисунок не описывается одним CSS браузера. Пропорции текстовых полей size/cols/rows приближены. Отступы блочных элементов учитываются, но полного браузерного схлопывания margin и расчёта viewport нет; подгонка итогового артборда выполняется отдельно. У фрагмента без body скрытый body с дополнительным отступом не создаётся.

Профиль действует на новый импорт. Уже сохранённый MSC содержит готовую геометрию и ключи, поэтому выбор другого профиля не меняет прежние проекты. Для пересчёта исходного компонента преобразуйте HTML/CSS заново с нужной настройкой.

Сравнить профили можно на browser-defaults.html и browser-defaults.css: в примере нет CSS-сброса сайта, поэтому видны исходные отступы текста и простых полей. Импортируйте оба файла с каждым профилем и сравните полученные редактируемые холсты.

Поддерживаемая часть

  • Контейнеры div, main, section, article, header/footer, nav/aside и простые семантические блоки. Фрагменты и полные документы с doctype/html/head/body читаются; служебные title/meta не попадают в рисунок. Иерархия сохраняется в группах, ID приводятся к допустимому уникальному имени.
  • Текст: h1–h6, p, span, label, strong/b, em/i, u/ins, s/del, small, sub/sup, code/pre и a. br делает настоящий перенос; hr становится разделителем; ul/ol/li получают маркеры и нумерацию. Сущности HTML, Unicode и кавычки сохраняются; буквальное \n в тексте кода отличается от настоящего переноса.
  • Селекторы тегов, #id, .class, их сочетания, списки через запятую, потомки и непосредственные дети >, :root и [disabled]. Учитываются специфичность, порядок деклараций, inline style и !important.
  • Цвета #RGB/#RGBA/#RRGGBB/#RRGGBBAA, rgb/rgba, основные имена цветов, currentColor и прозрачность. Наследуются цвет, размер, начертание и интервалы текста. CSS-переменные var с простым fallback наследуются; циклы и отсутствующие значения отмечаются.
  • width/height, padding/margin по четырём сторонам, gap, content-box/border-box. Единицы px, em и rem; width/height и позиционные отступы поддерживают проценты. Число без единицы разрешено для нуля. Размеры текста измеряются встроенным шрифтом Motif. У новых HTML-кнопок исходный box-sizing — border-box; для размеров содержимого указывайте content-box явно.
  • Поток блоков и строковых элементов, выравнивание текста по базовой линии, явные br, display:flex, flex-direction row/column, align-items/justify-content center или flex-start. Это вычисленные позиции; flex-grow, wrapping, grid и автоматический перенос по ширине не реализованы.
  • Заливка, равномерный радиус, рамки solid/double, линейный градиент без позиционных стопов, внешняя и внутренняя тень inset без ненулевого spread. Тени используют штатные редактируемые эффекты Motif; цвет и параметры теней могут иметь ключи. Размер шрифта, font-weight, font-family, line-height, letter-spacing, text-decoration и white-space. Наклонный текст передаётся редактируемым скосом. Для доступных встроенных семейств используются переносимые Sans/Serif/Mono; недоступные семейства отмечаются в предупреждениях.
  • :hover → Hover, :active → Press, :disabled → Disabled, :focus/:focus-visible → Focus. Состояния учитывают селекторы предков: например, button:hover .corner меняет дочерний элемент. Press включает применимые hover-правила.

Позиционирование, трансформации и маски

position:relative смещает элемент относительно обычного потока. position:absolute исключает его из потока и использует ближайшего позиционированного предка как содержащий блок. Поддерживаются top/right/bottom/left и процентные размеры; проценты позиции считаются от содержащего блока. Статический промежуточный контейнер не становится новым содержащим блоком. Для предсказуемого результата задавайте размеры позиционированного предка явно.

transform поддерживает двумерные translate/translateX/translateY, scale/scaleX/scaleY, rotate, skew/skewX/skewY и matrix с transform-origin. Порядок функций сохраняется. Преобразования записываются в свойства и группы сцены; рисунок остаётся векторным.

clip-path:polygon и -webkit-clip-path:polygon задают редактируемую векторную маску. overflow:hidden добавляет ограничение прямоугольником элемента. Если нужны оба ограничения, они пересекаются вложенными clip-группами. Маска скрывает лишнюю часть рисунка, не удаляя исходные контуры дочерних элементов.

Внутренняя тень inset отсчитывается от padding edge — внутреннего края рамки — и рисуется под обводкой. Для неё создаётся отдельная редактируемая фигура «Внутренняя тень». Например, у рамки 153×62 с толщиной 5 её размер будет 143×52. Это сохраняет прозрачные промежутки double-рамки; отсутствие заливки не превращается в белый фон.

Холст автоматически расширяется под видимые элементы, эффекты и опорные позы анимаций, чтобы вылетающие стрелки и тени не обрезались краем. Смещение холста задаёт нейтральная обёртка: ID, локальные координаты и ключи компонентов сохраняются. Для каждого клипа проверяется до 720 поз; при достижении лимита или предела 8192 единиц появляется предупреждение.

Переходы и CSS-анимации

transition задаёт длительность, задержку и кривую перехода между базовым видом и псевдосостоянием. @keyframes читается с from/to или процентными остановками. animation поддерживает список нескольких анимаций, задержки, кривые времени, число повторений, infinite, alternate и заполнение начального/конечного состояния. Изменения преобразуются в обычные ключи Motif, которые можно двигать и редактировать на таймлайне.

Конечная часть состояния сохраняется в штатном клипе Hover/Press/Focus/Disabled. Если у состояния есть бесконечное движение, рядом появляется клип с суффиксом Loop — например, HoverLoop. Он хранит повторяющуюся часть после входа в состояние. В UI-проверке редактора петля продолжается после входного клипа; на таймлайне её можно выбрать и проиграть отдельно.

Это дискретная запись поддерживаемых CSS-свойств в MSC, поэтому результат зависит от точности выборки и доступных векторных свойств. Неподдержанные свойства, слишком большие или несогласованные циклы и ограничения перечисляются в предупреждениях. Экспорт screen/kit передаёт статические картинки состояний и не создаёт CSS-движок в игре; непрерывное поведение следует воспроизвести игровыми средствами.

Входной клип и общий период петли ограничены 12 секундами. Целевой шаг выборки — 60 кадров в секунду; число обычных опор ограничено размером сцены и максимумом 720, дополнительно сохраняются остановки keyframes и границы задержек. В одном @keyframes допускается до 256 опор. Об уменьшении частоты или невозможности собрать общий период выдаётся предупреждение.

Изменение градиента, формы маски, типа обводки, межстрочного интервала line-height, жирности и текстовых декораций в состоянии сохраняет базовую форму с предупреждением. Маски и оформление можно доработать обычными средствами Motif после импорта.

Шрифты и переносимость

Arial, Helvetica, Liberation Sans и sans-serif разрешаются во встроенную Liberation Sans с совместимыми метриками. Times New Roman/Times/serif используют Liberation Serif, Courier New/Courier/monospace — Liberation Mono. Для каждого семейства доступны Regular 400 и Bold 700; сохраняются запрошенные размер и жирность. IBM Plex Sans также доступен; обычные существующие MSC со стандартными font regular/font bold используют прежние шрифты.

Списки font-family обрабатываются по порядку, неизвестные семейства и системные замены дают предупреждение. Системные папки шрифтов и @font-face не загружаются. Для CLI и генераторов MSC доступны встроенные имена font "builtin:css-sans-regular", font "builtin:css-serif-regular", font "builtin:css-mono-regular" и их варианты с окончанием -bold; рядом с MSC не требуется файл TTF.

Liberation Sans, Serif и Mono распространяются по SIL Open Font License 1.1; авторские сведения включены в комплект. Экспорт screen/kit с этими шрифтами сохраняет соответствующие TTF и уведомления. Совместимые метрики улучшают соответствие браузеру, но не означают побайтно одинаковую растеризацию текста.

Элементы форм передают графическую основу и существующие UI-роли Motif. Проверка HTML-форм, отправка данных, связь label/for, переход по href и обработчики событий не создаются. Конвертер перечисляет ограничения в предупреждениях.

Составная подпись с несколькими span/b/другими текстовыми фрагментами сохраняется целиком в векторном рисунке. Штатный экспорт screen/kit использует первый текстовый part как подпись контрола; многоцветный или смешанный текст для игрового контрола требует доработки. Импорт предупреждает об этом ограничении.

Что требует ручной доработки

Неподдерживаемые селекторы, свойства, единицы, внешние ресурсы и обработчики событий перечисляются в предупреждениях. Для неподдержанных at-rule, псевдоэлементов, трёхмерных transform, filter, URL-заливок, сложных радиусов, нескольких однотипных теней и адаптивной раскладки нужны дополнительные средства. Разные радиусы углов упрощаются до первого; 50% превращается в равномерную «пилюлю» с предупреждением. Многострочный вложенный inline-блок приближённо считается единым прямоугольником, о чём выдаётся предупреждение. Атрибут disabled задаёт базовый вид, но недоступность поведения следует задать в проверке UI или игре.

HTML трактуется как ограниченное дерево фрагмента с простым восстановлением незакрытых тегов. Оно не заменяет алгоритм DOM браузера для ошибочной вложенности. Обычные блоки не получают автоматическую браузерную ширину окна; задавайте размеры и flex-направление явно. Пределы: до 200 КБ HTML и CSS по отдельности, 2048 узлов и 2048 правил, глубина до 64, размер до 8192 единиц. Результат проверяется парсером MSC перед выдачей.

Как готовить код генератором

Попросите отдельный компонент без JS: явный button, простые вложенные div/span, размеры в px, именованные классы, ограниченный flex, обычные цвета, радиусы и рамки. Сначала конвертируйте, затем прочитайте предупреждения и поправьте исходник либо полученную фигуру. Такой процесс позволяет быстро получить редактируемую основу; точность переноса сложного web-компонента нужно оценивать по результату.

Источники логики CSS

Снимки базовых UA-правил от 30.10.2026 закреплены на официальных исходниках: Chromium html.css, 0441415b72b9; Gecko html.css и Gecko forms.css, d760e8dae63e. Firefox-профиль сверяется с исходниками; измерение нативного Firefox в текущем окружении не выполнялось. Это ограниченный перенос этих правил в Motif, а не копия полного UA stylesheet.

Для правил приоритетов использованы CSS Cascading and Inheritance Level 5, для padding/margin — CSS Box Model Level 3, для состояний — Selectors Level 4. Проверено 29.10.2026. Список выше описывает реализованное подмножество Motif, а не полную поддержку стандартов.

Расположение и размытие inset сверены 30.10.2026 с CSS Backgrounds and Borders 3: Shadow Shape и Shadow Blurring. Измерения точной кнопки в Chromium, снимки и воспроизводимый скрипт эталона сохраняются в локальной лаборатории вне Git; они не входят в сборку редактора.
