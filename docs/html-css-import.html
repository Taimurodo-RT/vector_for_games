Импорт HTML и CSS

Вставьте короткий HTML-фрагмент и его стили, чтобы получить обычные редактируемые группы, прямоугольники и текст. Разметка задаёт назначение элемента: button становится UI-кнопкой, label — меткой.

Первый этап, 29 октября 2026. Импорт предназначен для отдельных кнопок, карточек и коротких панелей, в том числе сгенерированных кодом. Он использует собственный ограниченный конвертер. Фрагмент не открывается в браузере, JavaScript не выполняется, внешние картинки и шрифты не загружаются.

В редакторе

Откройте импорт HTML/CSS из меню «Файл». Вставьте разметку в поле HTML, стили в поле CSS; встроенный блок style тоже читается. Выполните преобразование и просмотрите результат и предупреждения. Кнопка «Преобразовать» показывает превью и предупреждения. «Добавить UI-холст» добавляет результат в текущий документ отдельным холстом, сохраняя прежние сцены и анимации. Весь импорт отменяется одним Undo; фон, текст и группы остаются редактируемыми.

Пример находится в examples/import/button.html и button.css. В нём две кнопки со штатными Hover, Press, Disabled и Focus. Проверяйте их через «Проверить», таймлайн или правый предпросмотр.

Командная строка

motif import-html button.html --css button.css -o button.msc
motif check button.msc
motif render button.msc -o button.png
motif render button.msc --anim Hover --time 0.2 -o button-hover.png

Без -o команда пишет только MSC в stdout. Предупреждения идут в stderr. С -o создаются родительские папки и записывается новый файл; попытка записать поверх входного HTML или CSS отклоняется. Файл стилей указывается явно: link href не загружается. Для автоматизации доступна функция motif_html::import(html, css), возвращающая source, warnings и elements.

Поддерживаемая часть

  • Теги button, div, span, p, label, заголовки и простые контейнеры. Иерархия сохраняется в группах; текст остаётся текстом. HTML-сущности, кавычки и Unicode декодируются. ID сохраняются в допустимом формате и делаются уникальными.
  • Селекторы тегов, #id, .class, их сочетания, списки через запятую, потомки и непосредственные дети >, :root и [disabled]. Учитываются специфичность, порядок деклараций, inline style и !important.
  • Цвета #RGB/#RGBA/#RRGGBB/#RRGGBBAA, rgb/rgba, основные имена цветов, currentColor и прозрачность. Наследуются цвет, размер, начертание и интервалы текста. CSS-переменные var с простым fallback наследуются; циклы и отсутствующие значения отмечаются.
  • width/height, padding/margin по четырём сторонам, gap, content-box/border-box. Единицы px, em и rem; число без единицы разрешено для нуля. Размеры текста измеряются встроенным шрифтом Motif.
  • Простой поток столбцом или строкой, display:flex, flex-direction row/column, align-items/justify-content center или flex-start. Это линейная раскладка с вычисленными позициями; flex-grow, wrapping, grid и браузерное перетекание текста не реализованы.
  • Заливка, равномерный радиус, сплошная рамка, линейный градиент без позиционных стопов и одна внешняя тень без ненулевого spread. Размер шрифта, font-weight, line-height и letter-spacing. Используется встроенный IBM Plex Sans, внешняя font-family выдаёт предупреждение.
  • :hover → Hover, :active → Press, :disabled → Disabled, :focus/:focus-visible → Focus. Цвет, обводка, радиус и прозрачность превращаются в штатные ключи. Press включает применимые hover-правила. В этой версии переходы имеют длительность 0.2 с; CSS transition не переносится.

Что требует ручной доработки

Неподдерживаемые селекторы, свойства, единицы, внешние ресурсы и обработчики событий перечисляются в предупреждениях. Для at-rule, псевдоэлементов, transform, filter, URL-заливок, сложных радиусов, нескольких теней и адаптивной раскладки нужны дополнительные средства. Разные радиусы углов упрощаются до первого; 50% превращается в равномерную «пилюлю» с предупреждением. Изменение размеров или градиента/тени в псевдосостоянии не переносится и явно отмечается. Сброс градиента цветом через background в обычном состоянии поддержан; если такой сброс требуется в :hover, остаётся базовый градиент с предупреждением, ложный цветовой ключ не создаётся. Inline-текст внутри button/p с b/span сохраняет пробелы и строку; принудительный br пока заменяется пробелом с предупреждением. Атрибут disabled задаёт базовый вид, но недоступность поведения следует задать в проверке UI или игре.

HTML трактуется как ограниченное дерево фрагмента с простым восстановлением незакрытых тегов. Оно не заменяет алгоритм DOM браузера для ошибочной вложенности. Обычные блоки не получают автоматическую браузерную ширину окна; задавайте размеры и flex-направление явно. Пределы: до 200 КБ HTML и CSS по отдельности, 2048 узлов и 2048 правил, глубина до 64, размер до 8192 единиц. Результат проверяется парсером MSC перед выдачей.

Как готовить код генератором

Попросите отдельный компонент без JS: явный button, простые вложенные div/span, размеры в px, именованные классы, ограниченный flex, обычные цвета, радиусы и рамки. Сначала конвертируйте, затем прочитайте предупреждения и поправьте исходник либо полученную фигуру. Такой процесс позволяет быстро получить редактируемую основу; точность переноса сложного web-компонента нужно оценивать по результату.

Источники логики CSS

Для правил приоритетов использованы CSS Cascading and Inheritance Level 5, для padding/margin — CSS Box Model Level 3, для состояний — Selectors Level 4. Проверено 29.10.2026. Список выше описывает реализованное подмножество Motif, а не полную поддержку стандартов.
