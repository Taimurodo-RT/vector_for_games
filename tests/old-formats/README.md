# Файлы прошлых форматов

Каждый файл здесь обязан открываться в любой будущей версии Motif. Тест
`crates/motif-script/tests/old_formats.rs` открывает их все, проигрывает анимации и
проверяет, что после сохранения в текущем формате сцены остаются теми же.

- `unversioned/` — файлы до версий формата, без строки `motif N` (их читаем как версию 1).
  Это копии `examples/` от 30.10.2026.

Когда формат меняется несовместимо (растёт `motif_script::format::VERSION`), сюда
добавляется папка `v<N>/` с примерами прошлой версии. Файлы здесь не правятся.
